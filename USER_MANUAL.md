## Admin Side

### Login
- **Email:** admin@mail.com
- **Password:** admin1234
- Admin can log in using the credentials above to access full administrative features.

### Dashboard Overview
- Upon logging in, the admin sees an overview of all tasks and users.
- Widgets show task statistics, recent activity, and status summaries.

### Task Management
- Admin has access to the **Task Table** and **Kanban Board**.
- Admin can view **all tasks created by users**, regardless of ownership.
- **Features include:**
    - View task details
    - Create, edit, or delete tasks
    - Track task progress via the Kanban board

### User Management
- Admin has full access to user management based on **permission roles**.
- **Features include:**
    - Add new users
    - Edit user information
    - Disable or activate user accounts
    - Delete users
- Admin can assign different permission-based roles to users.

## User Side

### Registration
1. Go to the registration page.
2. Enter a valid email address and create a password.
3. An OTP (One-Time Password) will be sent to your email.
4. Enter the OTP to verify your email and complete registration.

### Login
- After successful registration, log in using your email and password.

### Dashboard Overview
- Once logged in, the dashboard displays **task widgets** including:
    - Pending tasks
    - Completed tasks
    - Task progress overview
- Users can quickly access the **Task Page** from the dashboard.

### Task Management
- Tasks can be managed using the **Kanban Board**, which allows users to:
    - Move tasks between columns (e.g., Pending, Completed)
    - Track task progress visually

---

## Notes
- Admin has **full control** over all users and tasks.
- Users can only manage tasks they have created.
- Ensure email verification is completed during registration for account activation.
